# Worm

Worm has been updated to support touchscreen devices. The new features include:

- **Screen-responsive layout**: The layout has been adjusted to adapt to the small screen sizes, making the game playable on mobile.
- **Touch input for worm direction**: The game now supports directional changes using touch input. The screen is divided into four quadrants:
  - Touch in **top-left** for diagonal movement up-left.
  - Touch in **top-right** for diagonal movement up-right.
  - Touch in **bottom-left** for diagonal movement bottom-left.
  - Touch in **bottom-right** for diagonal movement bottom-right.

Enjoy the new experience of playing the worm game, now optimized for touchscreen and mobile-friendly displays!
